# Статьи cephfix.com — как публиковать

Папка `_templates` не попадает на сайт (GitHub Pages пропускает папки, начинающиеся с `_`).

- `article.ru.html`, `article.en.html` — шаблоны страницы статьи.
- `publish.py` — единственный способ публикации. Создаёт страницы статьи
  (`articles/<slug>/`, `en/articles/<slug>/`), добавляет её в оба списка статей,
  в `sitemap.xml` и при первой публикации — ссылку «Статьи» в меню главной.

Порядок:
1. Подготовить `ru.html` и `en.html` — только тело статьи, без `<h1>`, без скриптов и картинок.
2. Подготовить `article.json` (формат — в начале `publish.py`).
3. Из корня репозитория: `python3 _templates/publish.py путь/к/article.json`
   (замена опубликованной статьи — с флагом `--update`).
4. Проверить `git status` (изменены только файлы, перечисленные скриптом), сделать коммит и push в `main`.

Не редактировать вручную `index.html`, `CNAME`, иконки, `robots.txt` и другие файлы сайта.
